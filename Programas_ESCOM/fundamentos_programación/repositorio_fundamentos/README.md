# Repositorio de Programas - Fundamentos de Programación

Colección de ejercicios prácticos basados en el programa sintético oficial:
- **Unidad I: Programación Estructurada**: Ciclos (for, while, do-while), arreglos unidimensionales, cadenas y matrices.
- **Unidad II: Apuntadores, Tipos de Datos Estructurados y Funciones**: Recursividad vs iteración, paso por valor y referencia, aritmética de apuntadores y structs.
- **Unidad III: Manejo de Memoria Dinámica y Archivos**: Asignación con malloc, calloc, realloc, operadores new/delete, y manejo de archivos de texto (.txt) y binarios (.dat).
