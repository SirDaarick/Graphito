# Archivo

Material de versiones anteriores del proyecto. Se conserva solo como historia y **no es comparable con los resultados actuales**.

| Carpeta | Qué contiene | Por qué está aquí |
| :--- | :--- | :--- |
| `benchmarks_modelos_anteriores/` | Resultados en JSON de los primeros benchmarks de GraphCodeBERT (`benchmark_baseline_*`) y de CharCNN (`benchmark_charcnn_*`). | Se midieron con un conjunto de validación antiguo que reutilizaba datos de entrenamiento y con umbrales fijos a mano. Los resultados vigentes están en `runs/` y se generan con la partición `split_v1`. |

Para ver qué modelo está en uso hoy, consulta `models/deploy/README.md`.
